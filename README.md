# theme-health-check

ตรวจสุขภาพ **ธีม** WordPress ทุกเว็บบนเซิร์ฟเวอร์ ด้วย PHP CLI ตัวเดียว รันตรงจาก GitHub ไม่ต้องเซฟไฟล์ เรียกใช้จากเซิร์ฟเวอร์ไหนก็ได้

ใช้ไล่หาธีมที่ไฟล์หายหรือเสียหาย เช่นโฟลเดอร์เหลือเปล่าหลัง auto-update พังกลางคัน หรือธีมแม่ (parent) ขาดไฟล์หลักจนเว็บพัง

> สคริปต์คู่แฝด: ตรวจปลั๊กอินใช้ `plugin-health.php` (คนละ repo) — ตัวนี้ตรวจธีมโดยเฉพาะ เพื่อความเร็ว

## คุณสมบัติ

- หาโฟลเดอร์ธีมที่ **ว่างเปล่า** / **ไฟล์น้อยผิดปกติ** / **ไม่มีไฟล์หลัก**
- **เกณฑ์แยกตามชนิดธีม** เพื่อความแม่นยำ (parent / child / ทั่วไป ใช้เกณฑ์ต่างกัน)
- **ตรวจ parent theme (blocksy) เข้มเป็นพิเศษ 2 ชั้น:**
  - เช็คไฟล์หลัก 3 ตัวครบไหม (`style.css`, `index.php`, `functions.php`)
  - นับจำนวนไฟล์รวม — ถ้า ≤ 50 = น่าสงสัยว่าไฟล์หายเยอะ
- จัดกลุ่มตามชื่อธีม + เรียงตามจำนวนเว็บที่กระทบ
- สแกนทุกเว็บใน /home หรือเจาะบัญชีเดียว
- รันแบบถ่อมตัว (low CPU/IO priority) ไม่รบกวนเว็บอื่น
- ออกผลตารางหรือ CSV
- **อ่านอย่างเดียว 100%** ไม่ลบ ไม่แก้ ไม่ย้ายไฟล์

## เกณฑ์การตรวจ (แยกตามชนิดธีม)

| ชนิดธีม | เกณฑ์ "สงสัย" | เหตุผล |
|---|---|---|
| **blocksy** (parent) | ขาดไฟล์หลัก 3 ตัว **หรือ** ไฟล์รวม ≤ 50 | ธีมเต็มต้องมีไฟล์เยอะ + ไฟล์หลักครบ |
| **blocksy-child** | ไฟล์ ≤ 2 | child theme ปกติมี 3 ไฟล์ (style.css, functions.php, screenshot) |
| **ธีมทั่วไปอื่น ๆ** | ไฟล์ ≤ 10 | ธีมทั่วไปไม่ควรมีไฟล์น้อยเกินไป |

## ประเภทปัญหาที่ตรวจจับ

| สถานะ | ความหมาย |
|---|---|
| `ว่าง!` | โฟลเดอร์ธีมว่างเปล่า ไฟล์หายหมด |
| `ไฟล์หลักขาด` | parent theme (blocksy) ขาด style.css/index.php/functions.php — ธีมพัง |
| `ไม่มีหลัก` | ธีมไฟล์เยอะแต่ไม่มี style.css ที่มี Theme Name |
| `สงสัย` | ไฟล์น้อยผิดปกติ (ตามเกณฑ์แต่ละชนิดธีมข้างบน) |
| `ปกติ` | มีไฟล์ครบและไฟล์หลักครบ |

> หมายเหตุ: ตรวจ "ความครบถ้วนของไฟล์" ไม่ใช่สแกนมัลแวร์

## วิธีใช้ (รันตรงจาก GitHub)

```bash
URL='https://raw.githubusercontent.com/ufavisionseoteam19/theme-health-check/main/theme-health.php'

# สแกนทั้งเครื่อง
curl -s "$URL?v=$(date +%s)" | php

# แสดงเฉพาะที่มีปัญหา (แนะนำสำหรับเว็บเยอะ)
curl -s "$URL?v=$(date +%s)" | php -- --only-issues

# เฉพาะบัญชีเดียว
curl -s "$URL?v=$(date +%s)" | php -- --user=newkeydec2025

# ออกผลเป็น CSV
curl -s "$URL?v=$(date +%s)" | php -- --csv > theme-health-$(date +%F).csv
```

## ตัวเลือก (Flags)

| Flag | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `--user=NAME` | สแกนเฉพาะบัญชีนี้ | ทุกบัญชีใน /home |
| `--base=PATH` | เปลี่ยนโฟลเดอร์ฐาน | /home |
| `--threshold=N` | ธีมทั่วไปมีไฟล์ ≤ N = สงสัย | 10 |
| `--maxdepth=N` | จำกัดความลึกการค้น | 4 |
| `--exclude=a,b,c` | ยกเว้นธีม (คั่นด้วยคอมมา) | - |
| `--csv` | แสดงผลเป็น CSV | ตาราง |
| `--only-issues` | แสดงเฉพาะตัวมีปัญหา | แสดงทั้งหมด |
| `--no-progress` | ปิดข้อความความคืบหน้า | แสดง |

### ปรับเกณฑ์เฉพาะ (แก้ในไฟล์)

ตัวแปรด้านบนของสคริปต์ ปรับได้ตามต้องการ:
```php
$THRESHOLD   = 10;             // ธีมทั่วไป: ไฟล์ <= ค่านี้ = สงสัย
$CHILD_NAME  = 'blocksy-child'; // ชื่อ child theme
$CHILD_MIN   = 2;              // child: ไฟล์ <= ค่านี้ = สงสัย
$PARENT_NAME = 'blocksy';       // ชื่อ parent theme ที่ตรวจเข้ม
$PARENT_MIN  = 50;             // parent: ไฟล์ <= ค่านี้ = สงสัย
```

## วิธีสร้าง / อัปไฟล์ขึ้น GitHub

สร้าง repo ใหม่:
1. github.com → New repository → ชื่อ `theme-health-check` → Create
2. Add file → Upload files → ลาก `theme-health.php` → Commit

อัปทับเวอร์ชันใหม่:
1. เข้า repo → คลิก `theme-health.php` → ไอคอนดินสอ (Edit)
2. ลบเนื้อหาเดิม วางใหม่ → Commit changes

## วิธีแก้เมื่อเจอปัญหา

สคริปต์ไม่แก้ไขให้ — ต้องลงมือเอง:
- **ว่าง! / ไม่มีหลัก / ไฟล์หลักขาด** → ติดตั้งธีมใหม่ทับ (อัปโหลด .zip ผ่าน Appearance → Themes → Add New → Upload)
- **blocksy แม่ขาดไฟล์หลัก** → ติดตั้งธีม Blocksy ตัวเต็มใหม่ (เว็บที่ใช้ child theme จะกลับมาทำงานทันที)

## ความปลอดภัย

- read-only ไม่มีคำสั่งเขียน/ลบ/แก้ไฟล์เว็บ
- `curl | php` ดึงโค้ดจาก GitHub มารันทันที — ควรเป็น repo ของคุณเองและตรวจโค้ดก่อนใช้บน production

## ข้อกำหนด

- PHP CLI (ทดสอบบน PHP 8.3 ใช้ได้ตั้งแต่ PHP 7.x)
- สิทธิ์อ่านโฟลเดอร์เว็บ (ปกติใช้ root)
